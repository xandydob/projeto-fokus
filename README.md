# ⏳ Projeto Fokus - Timer de Produtividade

O **Fokus** é uma aplicação web de gerenciamento de tempo que utiliza a técnica Pomodoro para ajudar usuários a alternar entre períodos de concentração e descanso. Este projeto foi desenvolvido durante o curso da Alura em parceria com o programa SCTEC.

## 🚀 Funcionalidades

- **Três Modos de Timer:** Foco (25 min), Descanso Curto (5 min) e Descanso Longo (15 min).
- **Customização Dinâmica:** O fundo da página, as imagens e as frases mudam conforme o contexto selecionado.
- **Áudio:** Opção de música relaxante de fundo e alertas sonoros para início, pausa e finalização dos ciclos.
- **Interface Responsiva:** Adaptado para visualização em desktops, tablets e smartphones.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica e atributos de dados (`data-contexto`).
- **CSS3:** Estilização com variáveis CSS, Flexbox, transições e Media Queries.
- **JavaScript (ES6):** Manipulação de DOM, eventos, manipulação de áudio e funções de temporização (`setInterval`).

## 🎨 Layout e Estilo

O projeto utiliza um design moderno com gradientes dinâmicos que refletem o estado atual do timer:
- **Foco:** Roxo/Azul escuro intenso.
- **Descanso Curto:** Tons esverdeados.
- **Descanso Longo:** Tons azulados.
